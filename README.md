# محفظتي (Mahfathati)

تطبيق Flutter احترافي لإدارة الحسابات الشخصية والمالية اليومية مع دعم اللغة العربية (RTL) وواجهة Material Design 3.

## الميزات الأساسية

- إدارة النفقات: إضافة/تعديل/حذف (النموذج الأساسي للإضافة متوفر).
- إدارة الدخل مع تقارير يومية/أسبوعية/شهرية.
- نظام وساطة الكروت والباقات (مزود ↔ عميل) مع تسويات تلقائية.
- نظام حسابات أشخاص (محفظة متعددة) ورصيد لكل حساب.
- نظام قيود مزدوجة (Double Entry) لكل حركة.
- قاعدة بيانات SQLite محلية تعمل بدون إنترنت.
- وضع ليلي تلقائي حسب إعداد النظام.
- نسخ احتياطي JSON قابل للتوسع لاحقًا للمزامنة السحابية.

## تصميم قاعدة البيانات

### الجداول

1. `accounts`
   - `id`, `name`, `kind`, `balance`
2. `categories`
   - `id`, `name`, `type`
3. `transactions`
   - `id`, `type`, `amount`, `from_account`, `to_account`, `date`, `description`, `category_id`, `linked_transaction_id`
4. `debts`
   - `id`, `account_id`, `direction`, `amount`

## منطق العمليات المزدوجة

- كل عملية تؤثر على حسابين على الأقل.
- التسوية بين عميل ومزود تنشئ عمليتين مرتبطتين:
  1) خصم دين العميل وتحويل نقدي.
  2) سداد نفس المبلغ للمزود تلقائيًا.
- يتم حفظ الربط باستخدام `linked_transaction_id`.

## بيانات تجريبية (Seed)

- حسابات افتراضية:
  - محفظتي النقدية
  - مزود افتراضي
  - عميل تجريبي
- تصنيفات:
  - مصروف: طعام، مواصلات، إنترنت
  - دخل: راتب، عمل حر

## طريقة التشغيل

```bash
flutter pub get
flutter run
```

## قابلية التوسع

- إضافة Firebase Sync لاحقًا بتخزين نفس الـ schema سحابيًا.
- إضافة API Layer دون تغيير واجهات التطبيق.
- إضافة مصادقة PIN/بصمة (الحزم موجودة ويمكن تفعيلها تدريجيًا).
- إضافة إشعارات استحقاق باستخدام `flutter_local_notifications`.

## تحسين احترافي مقترح

- صفحة Ledger كاملة (قيد يومية محاسبي):
  - Debit/Credit لكل حساب.
  - ميزان مراجعة مبسط.
